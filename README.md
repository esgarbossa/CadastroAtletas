# Cadastro de Atletas

Sistema simples de cadastro de times e atletas desenvolvido em Java.

O projeto foi criado com foco em praticar os fundamentos de programação orientada a objetos, uso de classes, listas, entrada de dados pelo terminal e estrutura de menu com `switch`.

## 📌 Sobre o projeto

O sistema permite cadastrar times, adicionar atletas a esses times e listar os elencos cadastrados.

Atualmente, os dados são armazenados apenas em memória durante a execução do programa. Ou seja, ao encerrar o sistema, os cadastros são apagados.

Este projeto foi feito de forma simples e inicial, com possibilidade de melhorias futuras, como persistência de dados, validações mais completas e criação de uma interface gráfica ou frontend.

## 🚀 Funcionalidades

- Cadastro de times
- Cadastro de atletas vinculados a um time
- Listagem dos times cadastrados
- Listagem dos atletas de cada time
- Menu interativo pelo terminal
- Validação básica para impedir cadastro de atleta sem time

## 🛠️ Tecnologias utilizadas

- Java
- Programação Orientada a Objetos
- ArrayList
- Scanner
- IntelliJ IDEA
